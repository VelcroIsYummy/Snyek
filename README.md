# Nitinol Based Snake Robot With Custom Designed Hardware and Software.
## (A Snakebot)[https://en.wikipedia.org/wiki/Snakebot] designed to explore and patrol autonomously.

This project is for the 2027 CARSF Science Fair, we plan to program it entirely in baremetal ASM. This project's CAD files are currently being designed in Autodesk Fusion. We have intent to add the following features:
- CV
- CSI-2
- BMS 1S12P 16500s
- Muscle driving
- Lidar
